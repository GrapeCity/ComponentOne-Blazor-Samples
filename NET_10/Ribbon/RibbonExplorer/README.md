## Blazor Ribbon
#### [Download as zip](https://grapecity.github.io/DownGit/#/home?url=https://github.com/GrapeCity/ComponentOne-Blazor-Samples/tree/master/NET_10/Ribbon/RibbonExplorer)
____
#### Demonstrates how to use C1ToolStrip and the Blazor Ribbon tool components in customer-facing application scenarios.
____
The sample includes:
* A document toolbar with buttons, toggle tools, selection tools, menus, and command feedback.
* Layout and overflow settings for horizontal, vertical, and constrained toolbars.
* A data-bound toolbar created with ItemsSource and ItemTemplate.
